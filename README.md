# PW2 - Programação Web 2

Projeto feito com foco em **PHP** Junto de **HTML, CSS e JavaScript**.
Feito como atividade da ETEC.

## Avaliação_PW2

a Pagina principal tem perguntas e repostas sobre php

tambem possui links para:

- Estruturas de decisão (if else/switch-case)
- Laços de repetição (For, while e do-while)
- Includes

Cada exercicio seguindo um padrão de um **resp.php** para cada ***ex.php**

## Upload de Imagem

Mini sistema que permite o usuario enviar uma foto para o sistema

- Aceitando somente .png, .jpg e .jpeg
- Enviar via formulario e mandar para o imagem.php
- Salvar no banco de dados o nome antigo da imagem e o novo nome (hash).
